# Security audit remediation: signed auth token

Context: remediate the unsigned `user_id:role:expires_at` auth token in `backend/routes/common.py`.
Acceptance criteria:
- Replace the plaintext token with HMAC-SHA256 or JWT.
- Token validation must verify signature, expiry, and current DB role/session state.
- Forged or tampered tokens must return 401.
- Existing login/register flows must still issue tokens.
- Add/adjust tests for forged token rejection and valid token acceptance.
- Keep the change scoped to authentication/common helpers and related tests.
