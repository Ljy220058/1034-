## 2. 高优先级风险检查项（可直接执行）

### 1. 伪造 Bearer token 提权
- 影响：攻击者读取到 token 格式后，构造 `成员ID:目标角色:未来时间` 形式的令牌访问 admin/leader 接口，越权读取成员、签到、工作区任务与 worker 信息。
- 代码位置：backend/routes/common.py:53-74
- 验证方法：使用任意有效 member id，构造 role 为 admin 或 leader、expires_at 为未来时间的 Bearer token，请求 GET /api/v1/members、GET /api/v1/task-queue/workers、GET /api/v1/activities/{activity_id}/checkins，确认服务端是否只依赖明文字段校验。不得在验证记录中保存完整 token。
- 建议修复方向：改为带签名的 JWT 或 itsdangerous 签名 token；校验 exp、sub、role、iss、aud；密钥只从环境变量读取；对 role 只信任数据库实时值。
- 修复代码方向：
```python
from datetime import datetime, timedelta, timezone
import os
from jose import JWTError, jwt

JWT_SECRET = os.environ['JWT_SECRET']
JWT_ALG = 'HS256'
TOKEN_TTL_HOURS = 7

def token_for_member(member):
    now = datetime.now(timezone.utc)
    payload = {
        'sub': str(member.id),
        'role': member.role,
        'iat': int(now.timestamp()),
        'exp': int((now + timedelta(hours=TOKEN_TTL_HOURS)).timestamp()),
        'iss': '1034-running-club',
        'aud': '1034-api',
    }
    return jwt.encode(payload, JWT_SECRET, algorithm=JWT_ALG)

def parse_token(token: str) -> CurrentUser:
    try:
        payload = jwt.decode(token, JWT_SECRET, algorithms=[JWT_ALG], audience='1034-api', issuer='1034-running-club')
        member_id = int(payload['sub'])
    except (JWTError, KeyError, ValueError) as exc:
        raise HTTPException(status_code=401, detail='invalid or expired token') from exc
    member = get_member(member_id)
    if member is None:
        raise HTTPException(status_code=401, detail='invalid or expired token')
    return CurrentUser(id=member.id, role=member.role, member=member)
```

### 3. 登录口无速率限制且密码使用单轮 SHA-256
- 影响：攻击者对手机号列表执行密码喷洒或暴力猜测；单轮 SHA-256 在数据库泄露后加速离线破解，扩大账号接管范围。
- 代码位置：backend/routes/auth.py:19-20，backend/routes/auth.py:34-44
- 验证方法：连续对同一 phone 和不同 password 调用 POST /api/v1/auth/login，确认无 429；检查 members.password_hash 是否为 64 位十六进制 SHA-256。
- 建议修复方向：使用 Argon2id 或 bcrypt 哈希；按 IP + phone 做失败计数和限速；登录成功后重置失败计数。
- 修复代码方向：
```python
from passlib.context import CryptContext
pwd_context = CryptContext(schemes=['argon2'], deprecated='auto')

def hash_password(raw: str) -> str:
    return pwd_context.hash(raw)

def verify_password(raw: str, stored: str) -> bool:
    return pwd_context.verify(raw, stored)

@router.post('/login', response_model=ApiResponse)
def login(payload: UserLogin, request: Request) -> ApiResponse:
    key = f"login:{request.client.host}:{payload.phone}"
    if too_many_failures(key):
        raise HTTPException(status_code=429, detail='too many login attempts')
    with connect() as connection:
        row = connection.execute('SELECT * FROM members WHERE phone = ?', (payload.phone,)).fetchone()
    if row is None or not row['password_hash']:
        record_failure(key)
        raise HTTPException(status_code=401, detail='invalid phone or password')
    expected = row['password_hash']
    if not verify_password(payload.password, expected):
        record_failure(key)
        raise HTTPException(status_code=401, detail='invalid phone or password')
    clear_failures(key)
```

    return ApiResponse(data=member_to_public(member))

### 10. leader 权限覆盖删除成员、公告修改与替任意成员签到
- 影响：leader 被攻陷后可删除普通成员、修改公告、替任意成员签到或取消报名，造成社群运营数据与活动记录被篡改。
- 代码位置：backend/routes/members.py:69-80，backend/routes/announcements.py:32-39，backend/routes/checkins.py:29-64，backend/routes/activities.py:53-70
- 验证方法：以 role=leader 登录，执行删除普通成员、PATCH 公告、替其他 member 签到、取消其他 member 报名；记录每个接口返回状态与数据库变化。
- 建议修复方向：拆分细粒度权限，例如 `member:delete`、`announcement:publish`、`checkin:manual_write`；leader 默认只拥有活动运营权限，删除成员和公告发布保留给 admin。
- 修复代码方向：
```python
ROLE_PERMISSIONS = {
    'admin': {'member:delete', 'announcement:publish', 'checkin:manual_write', 'registration:manage'},
    'leader': {'checkin:manual_write', 'registration:manage'},
    'member': set(),
}

def require_permission(current_user: CurrentUser, permission: str) -> None:
    if permission not in ROLE_PERMISSIONS.get(current_user.role, set()):
        raise HTTPException(status_code=403, detail='forbidden')

@router.delete('/{member_id}', response_model=ApiResponse)
def remove_member(member_id: int, current_user: CurrentUser = Depends(get_current_user)) -> ApiResponse:
    require_permission(current_user, 'member:delete')
    target = get_member(member_id)
    if target is None or target.role != 'member':
        raise HTTPException(status_code=404, detail='member not found')
    deleted = delete_member(member_id)
    if not deleted:
        raise HTTPException(status_code=404, detail='member not found')
    return ApiResponse(data={'deleted': True})
```
