# 创意任务验收冒烟清单

## 适用范围

本清单用于快速验收创意任务定时生成流程，重点确认每次触发只创建两张看板卡片、卡片内容保持中文、负责人存在、工作区固定正确，并且流程不会改写或阻塞已有业务任务状态。

固定工作区为：`dir:/root/autodl-tmp/projects/hermes-swarm-lab`。

## 已发现的相关入口

- 实现入口：`backend/kanban_helper.py`
- 回归测试入口：`tests/test_creative_task_creation_flow.py`
- 使用说明文档：`docs/creative-task-worker-guide.md`
- 诊断或审计文档示例：`docs/security-audit-2026-06-06-attachment-path-security.md`

## 轻量运行方式

优先只运行创意任务相关测试，避免长时间执行全量测试：

```bash
pytest tests/test_creative_task_creation_flow.py -q
```

如需确认基础导入没有语法错误，可运行：

```bash
python -c "import backend.kanban_helper"
```

## 冒烟检查项

| 序号 | 检查项 | 操作方式 | 期望结果 | 失败排查方向 |
|---|---|---|---|---|
| 1 | 每次生成正好两张卡片 | 运行 `pytest tests/test_creative_task_creation_flow.py -q`，重点查看“生成正好两个任务负载”用例 | 测试通过，任务负载数量等于 2 | 检查 `build_workspace_scoped_tasks()` 是否新增或删除了任务规格，确认定时任务没有循环重复创建 |
| 2 | 标题为中文 | 查看测试“写入中文标题和中文描述”，或人工检查 `create_task_payloads()` 返回的 `title` | 两个标题都包含中文字符，适合中文看板阅读 | 检查 `KanbanTaskSpec.title` 是否被英文模板、空字符串或机器生成占位符覆盖 |
| 3 | 描述为中文 | 查看测试“写入中文标题和中文描述”，或人工检查返回负载中的 `body` | 两个描述都包含中文，并说明交付内容和验收标准 | 检查 `KanbanTaskSpec.body` 是否缺失、被英文模板覆盖，或只包含路径和状态字段 |
| 4 | 负责人字段存在 | 查看测试“写入负责人字段”，或人工检查返回负载中的 `assignee` | 每张卡片的 `assignee` 都是非空字符串 | 检查创建规格是否传入空字符串、空白字符串或 `None`，确认异常信息包含“负责人不能为空” |
| 5 | 工作区类型正确 | 查看测试“写入指定目录工作区”，或人工检查返回负载中的 `workspace_kind` | `workspace_kind` 固定为 `dir` | 检查 `as_kanban_args()` 是否仍然写入 `workspace_kind: 'dir'`，避免误改为 `scratch` 或 `worktree` |
| 6 | 工作区路径正确 | 查看测试“写入指定目录工作区”，或人工检查返回负载中的 `workspace_path` | `workspace_path` 固定为 `/root/autodl-tmp/projects/hermes-swarm-lab` | 检查 `DEFAULT_WORKSPACE` 是否被改动，确认路径为绝对路径且未被相对路径替换 |
| 7 | 相对工作区会被拒绝 | 查看测试“相对工作区返回清晰错误” | 传入相对路径时抛出清晰错误，避免创建不可追踪工作区 | 检查 `Path(self.workspace).is_absolute()` 校验是否仍存在，确认错误不会被吞掉 |
| 8 | 重复调用不产生额外任务 | 查看测试“重复调用任务负载保持幂等不重复” | 连续两次生成结果一致，标题集合仍只有两个 | 检查去重签名、固定标题和负责人是否稳定，确认定时任务没有加入随机标题或时间戳 |
| 9 | 不阻塞已有业务任务 | 人工确认本次冒烟只调用负载生成或轻量测试，不调用修改已有任务状态的操作 | 已有业务任务状态不被改为 `blocked`、`done` 或其他状态 | 检查定时流程是否误调用状态更新接口；排查任何批量更新任务状态的代码路径 |
| 10 | 轻量测试可快速完成 | 运行 `pytest tests/test_creative_task_creation_flow.py -q` | 只执行创意任务创建流程相关用例，通常应在短时间内完成 | 如果运行时间异常，检查是否错误连接外部服务、扫描全库或触发真实看板写入 |

## 人工验收记录建议

每次定时生成后，可以记录以下信息，便于问题复盘：

- 触发时间。
- 实际生成卡片数量。
- 两张卡片的标题、负责人和工作区。
- 轻量测试命令及结果。
- 是否发现已有任务状态被意外修改。

## 通过标准

全部冒烟检查项满足期望结果，且轻量测试入口可以通过，才可认为本次创意任务定时生成流程通过验收。若任一检查项失败，应停止继续分发新卡片，并按失败排查方向定位具体入口。
