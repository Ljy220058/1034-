# 中文创意库标签摘要器

## 作用

`backend.creative_idea_tags` 提供一个轻量的中文创意库整理能力，用于扫描 Hermes Kanban 近期任务标题和正文，抽取趋势标签、生成去重指纹，并输出可被脚本或后端复用的 JSON/Markdown 摘要。

当前内置趋势标签包括：

- 跑步数据：跑量、配速、公里、签到、报名、训练等。
- 校园风格：校园、校区、社团、深技大、排行榜、挑战赛等。
- 瀑布流：瀑布流、卡片流、活动列表、信息流等。
- 导入向导：导入、向导、预检、错误文案、批量导入等。
- 看板调度：看板、任务、worker、分流、空闲、阻塞、重复、去重等。
- 文档方案：文档、指南、规格、报告、清单等。
- 安全权限：安全、权限、审计、token、密码、认证等。

## 去重规则

摘要器不会修改看板状态，只输出创建前诊断依据：

1. 同一工作区且目标产物路径相同：高风险，跳过创建。
2. 未完成任务与候选任务核心词重叠达到 45% 且不少于 3 个：高风险，跳过或改为下游任务。
3. 同一负责人在同主题上已有 ready/running/blocked：中高风险，避免并行创建。
4. 候选任务命中跑步数据、校园风格、瀑布流、导入向导等趋势标签时，必须检查相同标签下最近任务示例。
5. 允许评审、补充、测试类下游任务，但标题和正文必须写明上游产物与新增价值。

## 本地运行示例

在项目根目录执行：

```bash
HERMES_KANBAN_DB=/root/.hermes/kanban/boards/1034-runclub/kanban.db \
python scripts/generate_creative_idea_tags.py --limit 200
```

默认输出：

- `docs/中文创意库标签摘要.json`
- `docs/中文创意库标签摘要.md`

如果需要写到临时路径：

```bash
python scripts/generate_creative_idea_tags.py \
  --db /root/.hermes/kanban/boards/1034-runclub/kanban.db \
  --limit 50 \
  --json-out /tmp/creative-tags.json \
  --md-out /tmp/creative-tags.md
```

## 如何指导下一轮任务创意

1. 先查看 JSON 的 `summary.top_themes`，避开分数最高且已有多个示例的主题，除非新任务明确是评审、测试或补充。
2. 再查看 `duplicate_groups`，如果候选标题与某个指纹共享 3 个以上核心词，优先跳过或改写为下游任务。
3. 创建候选任务前，用 `dedupe_rules` 解释为什么允许创建，尤其要写明不同产物路径和新增价值。
4. 若当前高频主题集中在看板调度或文档方案，可以换到活动页、成员页、签到页、跑步数据导入等模块提出更具体的小任务。
