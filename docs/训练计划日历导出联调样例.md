# 训练计划日历导出中文联调样例

## 概述

本文档给前端和后端联调用。
它说明训练计划导出为 ICS（iCalendar 文件格式，日历订阅文件格式）时，
应如何组织输入、校验输出和展示失败提示。

当前仓库里训练计划日历导出还没有正式后端实现。
`tests/test_calendar_export.py` 用 `xfail` 标记了验收契约。
前端已有训练模板入口，位于 `frontend/training-templates.js`。
活动字段以 `backend/models.py` 中的 `ActivityCreate` 为准。

## 快速开始

用下面命令确认本文档包含 4 组联调样例，并能定位到相关测试契约。

```bash
grep -nE '单次训练|多活动排序|跨天训练|空训练计划|test_空训练计划|test_训练活动_跨天训练' \
  docs/训练计划日历导出联调样例.md tests/test_calendar_export.py
```

预期能看到本文档中的 4 个样例标题，以及测试文件里的跨天训练和空训练计划断言。

## 现有入口梳理

| 入口 | 路径 | 用途 | 联调口径 |
|------|------|------|----------|
| 训练模板前端 | `frontend/training-templates.js` | 展示 5K、10K、半马、全马训练模板 | 可作为训练计划草稿的数据来源 |
| 活动模型 | `backend/models.py` | 定义 `ActivityCreate` 字段 | 日历导出输入字段应与活动字段保持一致 |
| 日历导出测试 | `tests/test_calendar_export.py` | 定义 ICS 输出验收契约 | 后端实现前按测试断言联调 |

## 字段约定

### 输入字段

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 训练活动标题，最长 120 字。导出到 `SUMMARY` |
| start_time | datetime | 是 | 开始时间，使用 ISO 8601（国际标准时间格式）字符串。导出到 `DTSTART` |
| end_time | datetime | 是 | 结束时间，必须晚于或等于开始时间。导出到 `DTEND` |
| location | string 或 null | 否 | 集合地点。为空时不生成 `LOCATION` |
| description | string 或 null | 否 | 训练说明。导出到 `DESCRIPTION` |
| activity_url | string 或 null | 否 | 活动详情链接。导出到 `URL` |

### ICS 关键字段

| 字段 | 说明 | 示例 |
|------|------|------|
| `BEGIN:VCALENDAR` | 日历文件开始标记 | `BEGIN:VCALENDAR` |
| `VERSION:2.0` | 日历协议版本 | `VERSION:2.0` |
| `PRODID` | 生成方标识 | `-//Hermes Swarm Lab//Training Plan//ZH` |
| `BEGIN:VEVENT` | 单个日历事件开始标记 | 每个训练活动一个 `VEVENT` |
| `SUMMARY` | 日历事件标题 | `SUMMARY:周末长距离训练` |
| `DTSTART` | 开始时间，测试契约使用 UTC（Coordinated Universal Time，协调世界时）格式 | `DTSTART:20260607T070000Z` |
| `DTEND` | 结束时间，测试契约使用 UTC 格式 | `DTEND:20260607T090000Z` |
| `LOCATION` | 地点 | `LOCATION:奥森南园` |
| `DESCRIPTION` | 说明 | `DESCRIPTION:配速 6:00，完成后拉伸` |
| `URL` | 活动详情链接 | `URL:https://run.example.com/activities/42` |
| `END:VEVENT` | 单个日历事件结束标记 | 每个训练活动一个 `END:VEVENT` |
| `END:VCALENDAR` | 日历文件结束标记 | `END:VCALENDAR` |

## 样例一：单次训练

### 概述

单次训练导出用于验证字段完整时，一个活动能生成一个可订阅的日历事件。

### 输入字段

```json
{
  "activities": [
    {
      "title": "周末长距离训练",
      "start_time": "2026-06-07T07:00:00Z",
      "end_time": "2026-06-07T09:00:00Z",
      "location": "奥森南园",
      "description": "配速 6:00，完成后拉伸",
      "activity_url": "https://run.example.com/activities/42"
    }
  ]
}
```

### 预期 ICS 关键字段

```text
BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//Hermes Swarm Lab//Training Plan//ZH
BEGIN:VEVENT
SUMMARY:周末长距离训练
DTSTART:20260607T070000Z
DTEND:20260607T090000Z
LOCATION:奥森南园
DESCRIPTION:配速 6:00，完成后拉伸
URL:https://run.example.com/activities/42
END:VEVENT
END:VCALENDAR
```

### 前端展示口径

- 列表标题显示“周末长距离训练”。
- 时间显示为用户本地时区下的开始和结束时间。
- 地点显示“奥森南园”。
- 详情区域显示训练说明和活动链接。

### 失败提示

- 如果 `title` 为空，提示“训练标题不能为空”。
- 如果 `start_time` 缺失，提示“请选择训练开始时间”。
- 如果 `end_time` 缺失，提示“请选择训练结束时间”。
- 如果导出结果没有 `BEGIN:VEVENT`，提示“日历文件缺少训练事件”。

## 样例二：多活动排序

### 概述

多活动排序用于验证后端导出时按开始时间升序输出，而不是按前端提交顺序输出。

### 输入字段

```json
{
  "activities": [
    {
      "title": "晚间恢复跑",
      "start_time": "2026-06-08T19:00:00Z",
      "end_time": "2026-06-08T20:00:00Z",
      "location": "校园东操场",
      "description": "低强度恢复跑",
      "activity_url": "https://run.example.com/activities/44"
    },
    {
      "title": "清晨间歇跑",
      "start_time": "2026-06-07T06:00:00Z",
      "end_time": "2026-06-07T07:00:00Z",
      "location": "校园田径场",
      "description": "400 米间歇 6 组",
      "activity_url": "https://run.example.com/activities/43"
    }
  ]
}
```

### 预期 ICS 关键字段

```text
BEGIN:VEVENT
SUMMARY:清晨间歇跑
DTSTART:20260607T060000Z
DTEND:20260607T070000Z
LOCATION:校园田径场
END:VEVENT
BEGIN:VEVENT
SUMMARY:晚间恢复跑
DTSTART:20260608T190000Z
DTEND:20260608T200000Z
LOCATION:校园东操场
END:VEVENT
```

### 前端展示口径

- 日历预览按开始时间从早到晚展示。
- “清晨间歇跑”必须排在“晚间恢复跑”之前。
- 如果后端返回顺序与前端提交顺序不同，前端以日历时间顺序为准。

### 失败提示

- 如果两个事件顺序反了，提示“训练计划排序异常，请刷新后重试”。
- 如果某个活动没有结束时间，提示“训练计划中存在未填写结束时间的活动”。

## 样例三：跨天训练

### 概述

跨天训练用于验证夜跑、接力跑或长距离拉练跨过自然日时，日历结束日期不被截断。

### 输入字段

```json
{
  "activities": [
    {
      "title": "夜间接力拉练",
      "start_time": "2026-06-07T22:30:00Z",
      "end_time": "2026-06-08T01:30:00Z",
      "location": "深圳湾公园",
      "description": "分组接力，领队统一收队",
      "activity_url": "https://run.example.com/activities/45"
    }
  ]
}
```

### 预期 ICS 关键字段

```text
BEGIN:VEVENT
SUMMARY:夜间接力拉练
DTSTART:20260607T223000Z
DTEND:20260608T013000Z
LOCATION:深圳湾公园
DESCRIPTION:分组接力，领队统一收队
URL:https://run.example.com/activities/45
END:VEVENT
```

### 前端展示口径

- 列表中显示开始日期和结束日期，不能只显示开始日。
- 详情中说明“跨天训练”，避免成员误以为当天结束。
- 如果前端按本地时区展示，需要同时展示本地日期和本地时间。

### 失败提示

- 如果 `end_time` 早于 `start_time`，提示“训练结束时间不能早于开始时间”。
- 如果 ICS 中 `DTEND` 仍是开始日期，提示“跨天训练结束日期异常”。

## 样例四：空训练计划

### 概述

空训练计划用于验证用户还没有选择任何训练活动时，系统仍能生成合法日历壳或给出清晰空态。

### 输入字段

```json
{
  "activities": []
}
```

### 预期 ICS 关键字段

```text
BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//Hermes Swarm Lab//Training Plan//ZH
END:VCALENDAR
```

### 前端展示口径

- 训练计划列表显示“暂无训练活动”。
- 导出按钮可以置灰，并解释“请先添加训练活动”。
- 如果仍允许导出，下载文件只能包含 `VCALENDAR` 壳，不能包含 `VEVENT`。

### 失败提示

- 如果接口返回空字符串，提示“日历文件生成失败”。
- 如果空计划导出结果包含 `BEGIN:VEVENT`，提示“空训练计划不应包含训练事件”。

## 联调检查清单

| 检查项 | 操作 | 通过标准 |
|--------|------|----------|
| 单次训练 | 提交 1 个字段完整活动 | ICS 包含 1 个 `VEVENT` |
| 多活动排序 | 乱序提交 2 个活动 | ICS 中较早活动排在前面 |
| 跨天训练 | 提交跨自然日活动 | `DTEND` 日期晚于 `DTSTART` 日期 |
| 空训练计划 | 提交空数组 | ICS 只有 `VCALENDAR` 壳 |
| 中文内容 | 使用中文标题和说明 | `SUMMARY` 和 `DESCRIPTION` 保留中文原文 |
| 缺失地点 | `location` 传 `null` | ICS 不生成空 `LOCATION:` 行 |

## 注意事项

- 当前后端没有 `backend/calendar_export.py`，测试契约先定义预期行为。
- 本文档不声明已经存在的 HTTP API，因为当前仓库没有日历导出路由。
- 后端实现时应保持 CRLF（Carriage Return Line Feed，回车换行）行尾，即 `\r\n`。
- 失败提示应说明具体字段，不能只显示“导出失败”。
- 前端展示时间时应明确时区，避免 UTC 时间和本地时间混淆。
