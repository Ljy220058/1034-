# 跑团功能创意种子库

适用项目：`/root/autodl-tmp/projects/hermes-swarm-lab`

本文件整理了一份可持续扩展的“跑团功能创意种子库”，重点面向后续 backend、frontend、test、docs、review、quality-gate 等 worker 继续拆分任务。优先级是新增 docs / examples 类素材，不改业务代码，不等待其他运行中任务结束。

## 一、使用说明

1. 本文件提供的是创意种子，不是实现方案。
2. 每条种子都尽量写成可直接转成 kanban 标题的中文短句。
3. 每个方向至少提供 3 条种子，避免后续生成任务时缺题。
4. 每条种子都标注建议 worker、交付物类型、是否适合实现类 worker、是否更适合文档 / 审查 / 质量门禁 worker。
5. 为避免重复，本库刻意避开已在近期创意文档中高频出现的“跑步数据导入、瀑布流、校园风格、运营周报”这几类主题。

## 二、方向总览

| 方向 | 目标 | 建议优先 worker | 主要交付物类型 |
|---|---|---|---|
| 跑步数据导入 | 把第三方跑步数据接入、校验和错误定位说清楚 | backend-dev、test-engineer、docs-writer | 后端接口、导入说明、冒烟清单 |
| 训练计划 | 让成员能看懂训练计划、提醒和完成状态 | backend-dev、frontend-dev、docs-writer | 计划页面、提醒规则、说明文档 |
| 活动瀑布流 | 优化活动内容展示、封面、排序和空状态 | frontend-dev、quality-gate、docs-writer | 前端页面、验收清单、交互说明 |
| 校园挑战赛 | 组织挑战赛报名、排行、榜单和通知 | backend-dev、frontend-dev、test-engineer | 规则说明、页面原型、测试用例 |
| 成员运营 | 维护成员标签、活跃度、分层和触达策略 | data-modeler、docs-writer、code-reviewer | 数据契约、运营说明、审查报告 |
| 隐私授权 | 明确数据收集、授权、导出和删除边界 | code-reviewer、quality-gate、docs-writer | 权限说明、审查清单、合规文档 |

## 三、六个方向的创意种子

### 1. 跑步数据导入方向

建议 worker：backend-dev、test-engineer、docs-writer
适合实现类 worker：是
更适合文档 / 审查 / 质量门禁 worker：是

   - 目标 worker：backend-dev

## 五、后续扩展建议

- 如果后续要继续扩展，可以按“后端、前端、测试、文档、审查、质量门禁”六类再细分。
- 如果某个方向已经有实现任务，再补“验收、补充、审查”类下游种子，不要重复做新功能实现。
- 如果后面新增了成员签到、活动报名、通知中心等模块，可以把这些模块单独拆成新的种子组。

## 六、人工检查方法

1. 打开 `docs/` 目录下本文件和现有相关文档，确认没有重复主题。
2. 逐条检查每个方向是否至少有 3 条种子，且标题可直接转成 kanban 任务。
3. 随机抽查 5 条种子，确认它们都明确写了建议 worker 和交付物类型。
4. 如果要做进一步的 kanban 创意生成，可以把本文件中的“一句话种子”直接喂给后续 worker 使用。
