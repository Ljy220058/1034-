# 创意任务去重策略

## 一、背景与适用范围

本策略用于当前项目的看板创意任务创建前检查，目标是在不阻塞、不归档、不删除现有任务的前提下，减少相似任务被反复创建到同一工作区。策略适用于中文创意任务、方案文档任务、看板体验改进任务、自动分流任务、验收清单任务和重复预警相关任务。

当前主要工作区为 `dir:/root/autodl-tmp/projects/hermes-swarm-lab`。近期创意任务集中输出到 `docs/` 目录，常见交付物包括功能方案、路线图、清单、评审报告、测试方案和风险审计文档。创建新任务前，应先读取近期任务标题、正文摘要、负责人、工作区、状态、创建时间和目标产物路径，再决定是否创建。

本策略只约束“创建前是否继续创建新卡片”，不改变已有任务状态，也不要求阻塞已存在任务。

## 二、近期创意任务重复模式分析

近期看板中可以观察到以下重复模式：

1. 同名重复：多个任务使用完全相同或几乎相同标题，例如“中文创意：空闲后端任务聚合摘要接口”“中文创意：空闲前端筛选快捷栏”“中文功能创意：智能任务看板自动分流”等在短时间内多次出现。
2. 改写重复：标题从“创意任务中文合规自动评分器”改成“中文合规复核清单”“创意任务审核器”“合规校验报告”，但正文仍围绕标题中文、描述中文、负责人存在、工作区正确、数量校验等同一目标。
3. 同负责人重复：同一负责人连续收到同主题任务，尤其是后端、前端、评审、质量门禁类任务，容易形成并行处理边界不清的重复卡片。
4. 同工作区重复：大多数创意任务都指向 `dir:/root/autodl-tmp/projects/hermes-swarm-lab`，同一主题在同一工作区内重复创建时，往往会争用同一代码区域或同一文档目录。
5. 同产物重复：多个任务要求输出到 `docs/` 目录，若新任务的目标文档名称、章节结构或验收标准相近，最终会产生内容重叠的方案文档。
6. 批量创建重复：同一轮创意生成中可能同时产生两张或多张“空闲 worker、任务推荐、自动分流、重复告警”相关任务，虽然标题不同，但都服务同一个创建流程。
7. 下游关系不明：有些任务本应是评审、补充或实现已有文档，却没有在标题或正文中说明“基于哪个上游产物”，导致看起来像重新生成同一方案。

## 三、去重总原则

1. 先查后建：任何创意任务创建前都必须先检查近期任务，不允许只凭候选标题直接创建。
2. 强去重不改旧任务：命中强重复时只跳过新任务创建，不阻塞、不归档、不删除已有任务。
3. 中文标题不能只做完全匹配：必须先规范化标题，再比较关键词、语义目标和交付物路径。
4. 工作区优先级高于标题差异：同一工作区、同一负责人、同一时间窗口内的相似任务，即使标题不同，也应提高风险等级。
5. 产物路径优先级高于表述差异：只要目标产物路径相同或章节要求高度一致，就应按疑似重复处理。
6. 允许有明确上下游关系的相似任务：若新任务明确是“评审、补充、实现、迁移、复核”已有产物，并且产物路径不同，可以创建，但正文必须说明差异。

## 四、四类去重规则

### 1. 标题相似度规则

可执行规则一：标题规范化后再比较。

创建前将标题做统一处理：去掉首尾空格，统一全角半角，删除冒号、顿号、破折号等常见标点，合并连续空白，保留中文关键词。示例：“中文创意：空闲后端任务聚合摘要接口”和“空闲后端任务聚合摘要接口扩展”应进入同一候选集合。

可执行规则二：核心关键词重叠达到阈值时标记为疑似重复。

抽取标题中的核心词，例如“创意、任务、看板、空闲、后端、前端、分流、推荐、重复、去重、合规、验收、审查、摘要、接口、清单”。若新标题与近期待办、运行中、阻塞或刚完成任务的核心词重叠率达到六成以上，应标记为“标题相似”。

可执行规则三：同义改写应按主题聚类。

“审核器、评分器、校验报告、复核清单”在创意任务质量检查场景下应视为同一主题族；“推荐器、分流服务、快捷推荐面板”在任务派发场景下应视为同一主题族。命中同一主题族时，即使标题字面相似度不高，也要继续检查负责人、工作区和时间窗口。

可执行规则四：交付目标相同优先判重。

如果正文要求的产物路径、章节结构或验收标准高度一致，即使标题相似度不足，也应判为疑似重复。例如两个任务都要求输出 `docs/创意任务去重策略.md`，或都要求“至少六条规则和三个示例”，应优先跳过后创建的候选。

### 2. 负责人规则

可执行规则五：同一负责人短时间内不重复接收同主题任务。

若同一负责人在最近二十四小时内已有状态为待办、进行中、阻塞或刚完成的同主题创意任务，新任务默认跳过创建。只有当新任务明确说明它是对已有任务的评审、补充、实现或复核时，才允许继续。

可执行规则六：同一负责人已有运行中相似任务时提高敏感度。

如果负责人当前已有运行中的相似任务，只要新任务命中任一强主题词组，例如“创意任务加去重”“看板加调度”“验收加清单”“空闲加分流”，就应进入人工确认或直接跳过，避免同一 worker 并行处理边界相近的卡片。

可执行规则七：不同负责人不等于自动通过。

若负责人不同，但工作区相同、产物路径相同或目标相同，仍应判为疑似重复。不同负责人只能降低风险等级，不能抵消同产物或同目标造成的强重复。

### 3. 工作区规则

可执行规则八：同一工作区内按目标产物强去重。

当候选任务工作区为 `dir:/root/autodl-tmp/projects/hermes-swarm-lab`，且目标产物路径与近期任务相同，必须跳过创建。若产物路径不同但都位于 `docs/` 且主题相同，应要求新任务正文说明它与已有文档的关系。

可执行规则九：同一工作区内按功能区域弱去重。

若两个任务不输出同一文件，但都修改或设计同一功能区域，例如“空闲 worker 推荐”“任务自动分流”“重复告警”“中文合规检查”，应标记为中风险。创建者需要确认新任务是独立实现、补充测试、文档评审还是下游迭代。

可执行规则十：跨工作区标题相似只做提醒。

如果标题相似但工作区不同，不应直接阻止创建；应返回低风险提示，要求确认目标项目、工作区和产物路径没有误填。若正文仍引用当前项目固定工作区，则按同工作区重复处理。

### 4. 创建时间规则

可执行规则十一：待办、进行中、阻塞任务无过期时间。

只要已有相似任务仍处于待办、进行中或阻塞状态，新候选就不应创建。原因是旧任务尚未产生可复用结论，继续创建只会增加并行冲突。

可执行规则十二：已完成任务设置七十二小时强去重窗口。

对已完成任务，若七十二小时内存在同主题、同负责人或同产物任务，新候选默认跳过。若必须创建，正文必须写明新增价值，例如“补充示例、更新规则、实现路线图第三项、复核旧结论”。

可执行规则十三：三十天内历史任务设置弱提醒窗口。

对七十二小时以前、三十天以内完成的相似任务，不强制阻止，但创建前必须提示历史任务标题、负责人和产物路径。新任务正文应说明为什么旧产物不足以复用。

可执行规则十四：同一批候选之间也要互相去重。

批量创建两张或多张创意任务时，既要与已有任务比较，也要在候选内部比较。若同一批候选中出现相似标题、相同负责人、相同工作区或相同产物路径，应只保留优先级最高、目标最清晰的一张。

## 五、创建前检查流程

1. 收集候选任务字段：标题、正文摘要、负责人、工作区、目标产物路径、创建来源、预计创建时间。
2. 读取近期看板任务：至少包含待办、进行中、阻塞，以及最近三十天完成的任务。
3. 过滤相关范围：优先保留同工作区任务、同负责人任务、标题含“创意、看板、任务、空闲、分流、去重、验收、合规、推荐、审查”的任务。
4. 规范化标题和正文：抽取中文核心词、同义主题族、产物路径、验收指标和核心动词。
5. 执行标题相似度检查：完全相同、关键词重叠、同义主题族、交付目标相同依次判断。
6. 执行负责人检查：同负责人二十四小时窗口、当前运行中相似任务、不同负责人但同产物风险。
7. 执行工作区检查：同工作区同产物强阻止，同工作区同功能区域中风险，跨工作区弱提醒。
8. 执行创建时间检查：待办、进行中、阻塞强阻止；七十二小时内完成强阻止；三十天内完成弱提醒。
9. 生成中文诊断结果：包含是否允许创建、风险等级、命中的已有任务、触发规则、建议改写方向。
10. 只创建允许创建的任务；对跳过任务输出失败提示；若所有候选都被跳过，本轮调度以“无新任务创建”正常结束。

## 六、失败提示文案

### 1. 标题和产物路径强重复

本轮跳过创建：候选任务“{新任务标题}”与近期任务“{已有任务标题}”疑似重复。触发规则：标题核心词高度重叠，且目标产物同为“{产物路径}”。建议：复用已有任务，或将新任务改写为明确的评审、补充或实现任务，并更换产物路径。

### 2. 同负责人同主题运行中

本轮跳过创建：负责人“{负责人}”已有运行中的同主题任务“{已有任务标题}”。触发规则：同一负责人、同一工作区、主题关键词重叠。建议：等待现有任务完成后再创建下游任务，或改派给合适的评审负责人并说明上下游关系。

### 3. 同工作区同功能区域中风险

创建前请确认：候选任务“{新任务标题}”与已有任务“{已有任务标题}”都指向同一工作区和同一功能区域。当前不一定阻止创建，但任务正文必须说明新增价值，例如补充测试、实现文档方案、评审旧产物或修复具体缺陷。

### 4. 跨工作区标题相似弱提醒

创建前请确认：候选任务“{新任务标题}”与历史任务“{已有任务标题}”标题相似，但工作区不同。当前不会自动阻止创建；请核对工作区是否填写正确，并在任务正文说明该工作区的独立目标。

### 5. 历史任务可能已覆盖

创建前请确认：过去三十天内已有相似已完成任务“{已有任务标题}”，产物为“{已有产物路径}”。如果新任务仍需创建，请在正文写明旧产物不能复用的原因，以及本次新增内容。

### 6. 批量候选内部重复

本轮仅保留一张候选任务：批量候选中“{候选甲标题}”与“{候选乙标题}”主题、负责人和工作区均相同。建议将两者合并为一张目标更清晰的任务，或拆分为有父子依赖关系的上下游任务。

## 七、示例

### 示例一：应跳过的重复文档任务

已有任务：“整理看板创意任务去重策略”，负责人为“default”，工作区为 `dir:/root/autodl-tmp/projects/hermes-swarm-lab`，产物为 `docs/创意任务去重策略.md`，状态为进行中。

候选任务：“补齐创意任务重复预警和去重规则”，负责人仍为“default”，工作区相同，正文也要求输出标题相似度、负责人、工作区、创建时间四类规则。

判断：跳过创建。原因是已有任务仍在进行中，且标题关键词“创意任务、重复、去重、规则”高度重叠，交付目标相同。

### 示例二：应跳过的同名实现任务

已有任务：“中文创意：空闲后端任务聚合摘要接口”，负责人为“backend-dev”，工作区为当前项目，状态为进行中。

候选任务：“空闲后端任务聚合摘要接口扩展”，负责人仍为“backend-dev”，正文要求汇总空闲 worker、待办任务、运行中任务与重复告警，并返回中文摘要字段。

判断：跳过创建或改为下游任务。原因是同一负责人、同一工作区、同一功能区域，而且旧任务尚未完成。若确需创建，应改写为“评审聚合摘要接口实现”或“补充聚合摘要接口测试”，并引用上游任务。

### 示例三：可创建但必须说明差异的评审任务

已有任务：“生成中文功能创意示例库”，产物为 `docs/chinese-feature-ideas.md`，状态为完成。

候选任务：“评审中文功能创意示例库的可执行性”，负责人为“code-reviewer”，工作区相同，产物为 `docs/中文功能创意示例库评审.md`。

判断：允许创建。原因是新任务不是重新生成示例库，而是评审已有文档；负责人不同、产物路径不同，且正文说明了“检查路径准确性、步骤完整性和示例可执行性”。

### 示例四：跨工作区弱提醒

已有任务：“整理看板调度体验改进路线图”，工作区为 `dir:/root/autodl-tmp/projects/hermes-swarm-lab`。

候选任务：“整理看板调度体验改进路线图”，工作区为另一个社团网页项目。

判断：不直接阻止，但返回弱提醒。创建者必须确认这是另一个项目的独立路线图，而不是误填工作区；如果正文仍引用当前项目，则应按同工作区重复处理并跳过。

### 示例五：批量候选内部重复

候选甲：“建立创意任务验收冒烟清单”，负责人为“quality-gate”，产物为 `docs/创意任务验收冒烟清单.md`。

候选乙：“补齐创意任务验收结果结构”，负责人也为“quality-gate”，产物仍为 `docs/创意任务验收冒烟清单.md`。

判断：只保留目标更明确的一张，另一张跳过或改为下游评审任务。原因是同一批次、同一负责人、同一产物路径会让 worker 无法区分主任务。

## 八、建议诊断结果格式

创建前检查可以输出以下中文字段，方便调度器或人工快速判断：

- 是否允许创建：是或否。
- 风险等级：高、中、低。
- 命中规则：例如“同工作区同产物”“同负责人同主题运行中”“三十天内历史相似”。
- 命中任务：已有任务编号和标题。
- 相似原因：标题关键词、负责人、工作区、时间窗口或产物路径。
- 处理建议：跳过、改名、改派负责人、改为评审任务、补充上下游关系或继续创建。

这些字段只用于创建前解释，不替代任务编号，也不应写入密钥、令牌或其他敏感信息。

## 九、落地建议

1. 先实现只读诊断模式，确保去重检查不会修改现有任务状态。
2. 将强去重规则用于自动跳过，将弱提醒规则写入调度日志或创建前提示。
3. 对每次跳过的候选任务保留中文诊断输出，方便后续调整阈值。
4. 每周抽查被跳过的候选，判断是否存在误杀；若误杀较多，降低标题权重，提高产物路径、正文目标和上下游关系权重。
5. 对真正需要重复派发的任务，要求标题包含明确关系词，例如“复核、补充、实现、更新、迁移、评审”，并在正文引用上游产物路径。
