# 1034 跑团管理系统空白状态文案规范

本文档定义 `frontend/` 页面与组件在空白、异常和加载场景下的中文提示文案。所有文案应保持简短、明确、可行动，优先告诉用户“当前发生了什么”和“下一步可以做什么”。

## 文案原则

- 语气：清晰、友好、不过度打扰，避免技术黑话直接暴露给用户。
- 结构：标题说明状态，描述补充原因，操作按钮给出下一步。
- 长度：标题建议 6–14 个中文字符，描述建议 1 句话，按钮建议 2–6 个中文字符。
- 一致性：相同场景复用同一套词，不在不同页面使用含义相近但表达不同的提示。
- 可恢复：错误与无结果状态必须提供重试、清空筛选或返回入口等行动建议。

## 列表页空状态

适用场景：成员列表、任务列表、跑团记录列表、活动列表等接口请求成功但返回空数组。

| 元素 | 推荐文案 | 使用说明 |
| --- | --- | --- |
| 标题 | 暂无数据 | 通用列表空态，适合无筛选条件时使用。 |
| 描述 | 当前还没有可展示的内容，创建后会显示在这里。 | 用于可新增资源的列表页。 |
| 主按钮 | 新建记录 | 根据页面资源替换为“新建成员”“创建任务”“添加活动”。 |
| 次按钮 | 刷新列表 | 适合数据可能刚刚变更但尚未显示的场景。 |

页面示例：

```text
暂无数据
当前还没有可展示的内容，创建后会显示在这里。
[新建记录] [刷新列表]
```

## 详情页空状态

适用场景：详情页局部模块无内容，例如成员备注为空、任务描述为空、活动统计尚未生成。

| 元素 | 推荐文案 | 使用说明 |
| --- | --- | --- |
| 标题 | 还没有补充信息 | 用于详情页中的可选信息区块。 |
| 描述 | 完善资料后，这里会展示更完整的跑团信息。 | 用于成员、队伍或活动详情。 |
| 主按钮 | 去完善 | 用户有编辑权限时显示。 |
| 只读描述 | 暂无补充内容。 | 用户无编辑权限或只读模块使用。 |

页面示例：

```text
还没有补充信息
完善资料后，这里会展示更完整的跑团信息。
[去完善]
```

## 搜索无结果

适用场景：搜索、筛选、标签过滤后接口请求成功但没有匹配项。

| 元素 | 推荐文案 | 使用说明 |
| --- | --- | --- |
| 标题 | 没有找到匹配结果 | 搜索关键词或筛选条件无命中时使用。 |
| 描述 | 试试更换关键词，或清空筛选条件后重新查看。 | 引导用户恢复到更宽泛的结果集。 |
| 主按钮 | 清空筛选 | 有筛选条件时优先显示。 |
| 次按钮 | 重新搜索 | 搜索请求可手动触发时显示。 |

页面示例：

```text
没有找到匹配结果
试试更换关键词，或清空筛选条件后重新查看。
[清空筛选] [重新搜索]
```

## 网络错误

适用场景：`fetch` 请求失败、接口超时、后端服务不可用或返回不可恢复错误。

| 元素 | 推荐文案 | 使用说明 |
| --- | --- | --- |
| 标题 | 数据加载失败 | 通用网络或接口错误标题。 |
| 描述 | 网络连接不稳定，或服务暂时不可用，请稍后重试。 | 避免直接展示后端错误堆栈。 |
| 主按钮 | 重试 | 绑定重新请求当前接口。 |
| 次按钮 | 返回上一页 | 详情页或关键流程中可选。 |

页面示例：

```text
数据加载失败
网络连接不稳定，或服务暂时不可用，请稍后重试。
[重试]
```

## 数据加载中

适用场景：首次进入页面、切换筛选条件、分页加载或详情模块刷新中。

| 元素 | 推荐文案 | 使用说明 |
| --- | --- | --- |
| 标题 | 正在加载数据 | 首屏或整页加载时使用。 |
| 描述 | 请稍候，正在同步最新跑团信息。 | 适合列表和详情页通用加载态。 |
| 行内文案 | 加载中… | 按钮或小区域加载时使用。 |
| 分页文案 | 正在加载更多 | 上拉或点击加载下一页时使用。 |

页面示例：

```text
正在加载数据
请稍候，正在同步最新跑团信息。
```

## 场景命名建议

建议在前端代码中按状态统一命名，便于后续复用：

- `empty`：接口成功但无数据。
- `empty-filtered`：筛选或搜索后无匹配结果。
- `loading`：数据请求中。
- `error-network`：网络错误或请求失败。
- `error-server`：服务返回错误但页面可恢复。
- `readonly-empty`：只读详情模块无内容。

## 禁用与加载按钮文案

- 提交中：`保存中…`、`创建中…`、`同步中…`
- 不可用：`暂无权限`、`请先选择成员`、`等待数据加载`
- 重试中：`重试中…`

按钮禁用时应保留可理解的文案，不使用空按钮或仅图标按钮。

## 可访问性建议

- 空状态容器应使用页面语义结构，例如 `section` 或 `article`。
- 加载状态建议使用 `aria-live="polite"`，错误状态建议使用 `role="alert"`。
- 只靠颜色无法表达状态，图标、标题和描述需要同时传达含义。
- 移动端下按钮可纵向排列，但文案不应截断到难以理解。
