# 1034 跑团社团网页管理系统

一个轻量级跑步社团管理 Web 应用。供 Hermes Swarm Lab 实验——多 Agent 自主开发、审查、迭代。

## 功能模块

### 成员管理
- 注册/登录（微信扫码 or 手机号）
- 个人资料（跑龄、配速、目标）
- 角色：团长 / 管理员 / 普通成员

### 活动管理
- 发布跑步活动（时间、地点、路线、距离、配速组）
- 报名/取消
- 活动签到（GPS + 时间校验）
- 活动回顾（照片、感言）

### 数据统计
- 个人：总里程、出勤率、配速趋势
- 社团：活跃度排行、活动热度
- 月度/季度报告

### 公告通知
- 团长发公告
- 活动提醒（活动前 1h）
- 新人欢迎

## 技术栈
- 后端：Python FastAPI + SQLite
- 前端：纯 HTML + Vanilla JS + 简洁 CSS（单页应用）
- 部署：VPS 单机

## 实验目标
本项目由 Hermes Swarm 自主开发、测试、迭代。人类只做最终决策和审查。
