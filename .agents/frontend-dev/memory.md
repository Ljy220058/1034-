     1|## frontend-dev 任务经验
     2|- 活动分享卡片适合拆成「数据摘要 + 预览画布 + 复制链接」三层结构，先用一套 CSS 变量统一控制圆角、间距和暗色层级，再在组件内部做状态切换。
     3|- 生成分享预览图时，用 canvas 先绘制渐变背景、封面图、标题和信息标签，再把输出转成 dataURL 供下载/复制，能避免依赖后端图片服务。
     4|- 375px 适配的关键是把卡片主轴改成单列、让按钮宽度 100%、并给预览画布设置 max-width: 100% 与自适应高度，才能稳定避免横向滚动。
- 成员仪表盘适合沿用 panel-state、summary-chip 与 panel-empty 这套现有状态词汇，这样新增模块能和旧页面保持统一，同时更容易覆盖 loading / empty / error / retry。
- 徽章墙里“已获得 / 未获得”两类卡片可以共用同一套网格，只通过状态类切换边框、背景和进度条，能减少 CSS 分叉并保持 375px 下稳定换行。
